# SYNTHESIS PROCEDURE
## BIO-WEAVE — PVDF-TrFE/Silk Fibroin/BaTiO₃ NP

---

## Protocol Summary
PVDF-TrFE in DMF:acetone → silk fibroin in HFIP → blend 70:30 + 5wt% BaTiO₃ → electrospin 18kV → pole 30MV/m at 90°C → anneal 70°C 24h

## Safety Notes
- Follow all institutional safety protocols for chemical handling
- Use appropriate PPE (lab coat, safety glasses, gloves)
- Work in fume hood for volatile/toxic materials
- Consult MSDS for all reagents before beginning

## Quality Control Checkpoints
1. Phase purity: XRD pattern matching
2. Morphology: SEM/TEM imaging
3. Key property verification: d₃₃=28 pC/N (2× PVDF-TrFE). Fiber 280-450nm. Degradation 2-18mo. Cell viability 96.3%. UTS 3.8MPa.
4. Reproducibility: minimum 3 independent synthesis runs

## Characterization Required
- Primary: Verify d₃₃=28 pC/N (2× PVDF-TrFE). Fiber 280-450nm. Degradation 2-18mo. Cell viability 96.3%. UTS 3.8MPa.
- Secondary: Long-term stability testing
- Validation gap: hMSC culture, ALP assay, Alizarin Red. In vivo rat calvarial defect. d₃₃ under physiological strain.

## Troubleshooting
- If properties don't match predictions, check synthesis temperature/time first
- Contamination and moisture are the most common failure modes
- Document ALL deviations from protocol
